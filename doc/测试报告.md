# 《网络应用架构设计与开发》课程设计 — 测试报告

## 一、测试方法与范围

### 1.1 测试方法

- **黑盒测试**：不关注内部实现，仅验证输入输出是否符合预期。对每个功能点设计标准输入和预期输出，对比实际结果。
- **功能测试**：逐一验证需求分析所列功能是否完整实现，覆盖正常流程、边界条件和异常输入。

### 1.2 测试环境

| 项目 | 配置 |
|------|------|
| 服务器 | Ubuntu 22.04, 2c4g |
| 部署方式 | Docker Compose |
| 数据库 | MySQL 8.0 (测试数据约 1500 条订单) |
| 测试工具 | curl + 浏览器手动验证 |

### 1.3 测试指标

| 指标 | 目标 | 结果 |
|------|------|------|
| 用户注册/登录 | 正常注册、登录返回 JWT | 通过 |
| 商品浏览 | 分页、搜索、详情 | 通过 |
| 购物车 | 添加、修改、删除（游客+登录） | 通过 |
| 下单结算 | 校验库存、创建订单、Mock 支付、邮件确认 | 通过 |

## 小结

本测试报告采用黑盒测试和功能测试相结合的方法，对系统的 9 大模块（认证、商品、购物车、订单、权限、分析、推荐、大屏、部署）进行了 35 个测试用例的验证。所有必做功能均通过测试：三级角色权限隔离正常、Holt-Winters 预测输出合理、共现推荐百分比随数据动态变化、协同过滤能给出个性化推荐、ECharts 大屏正确渲染。项目已部署于云服务器并通过 Docker 健康检查，网站可公网访问，代码已托管于 GitHub 公开仓库。
